prompts/validator.md →

Runnable agent. The context, prompt and validator are wired into an executable pipeline in ../agent/: point it at a repository, it discovers processes, builds CPM JSON, validates it, verifies every quote and writes BPMN plus documentation. Start with agent/README.md.

Two questions, two answers. Identity asks whether the payload is an ordered, actor-bound, outcome-producing set of activities. Compliance asks whether that process satisfies the model contract. A field list is never accepted because its JSON is valid; a real process without lanes is partial, not rejected. Run python3 prompts/validate_extraction.py --self-test to check all nine labelled fixtures.
